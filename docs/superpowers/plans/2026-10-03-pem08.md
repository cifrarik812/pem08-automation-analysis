# PEm08 Implementation Plan

> For agentic workers: use superpowers:executing-plans task by task.

**Goal:** адаптировать каркас урока для анализа n8n, Make, Albato, проверить результаты и сохранить черновик.
**Architecture:** сохраняются FastAPI, Selenium, Web UI и PyQt6. Сервис GigaChat реализует исходные методы анализа, схемы проверяют JSON, локальная история хранит полные результаты.
**Tech Stack:** Python, FastAPI, Pydantic, Selenium, PyQt6, PyInstaller, GigaChat REST.
**Spec:** docs/superpowers/specs/2026-10-03-pem08-design.md (одобрена пользователем).

## Global Constraints

Ключ только во внешнем .env; TLS включён; сервер только localhost. Три публичных источника: n8n, Make, Albato. Провайдер и редактор обозначены честно. На платформе только черновик. Публикация конкретного публичного репозитория после подготовки и проверки файлов.

## Review Focus

- Некорректный JSON не становится успешным пустым анализом — задача 1.
- Изображение под чужим MIME и слишком большой файл отклоняются — задача 1.
- URL с чужим хостом/учётными данными отклоняется до Selenium — задача 2.
- Параллельные записи не теряют историю; повреждение файла не затирается — задача 2.
- EXE без запущенного backend показывает понятную ошибку; вызов API не замораживает окно — задача 3.
