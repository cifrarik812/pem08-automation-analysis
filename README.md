# PEm08 — анализ n8n, Make, Albato

Учебная адаптация https://github.com/Toxap/pem08, исходный коммит 14e826dc639ae777fc3eb7abb088d6a952fcedd6. Сохранены FastAPI, Selenium, Web UI и PyQt6. Работа выполнена в Codex; OpenAI/ProxyAPI заменён существующим GigaChat по согласованию. Это отклонение от задания.

## Запуск

Python 3.11, Windows. Создай venv и установи requirements.txt. Укажи переменную процесса PEM08_ENV_FILE с абсолютным путём к внешнему .env (образец: env.example.txt). Запусти python run.py и открой http://127.0.0.1:8008. Ключ остаётся вне репозитория, TLS включён, сервер только localhost.

Текст: GigaChat-2; изображения: GigaChat-2-Pro. В проверенном аккаунте GigaChat-2 отвергал изображения с HTTP 422. Параметр GIGACHAT_VISION_MODEL задаётся переменной процесса. Для TLS доступен GIGACHAT_CA_BUNDLE — путь к доверенному CA-файлу.

## Возможности

/analyze_text: 10–16000 символов, design_score=null. /analyze_image: настоящие PNG/JPEG до 10 MiB, максимум 8192 по стороне и 24 млн пикселей. /parse_demo: Selenium, только https://n8n.io/, https://www.make.com/en, https://albato.ru/. Нужен Chrome и доступ Selenium Manager к драйверу. Проверки доступа сайтов не обходятся.

/history: последние десять полных результатов с источником и временем. Атомарная запись в outputs/history.json. Повреждённый файл не затирается. История рассчитана на один серверный процесс. Неправильный JSON модели возвращается как ошибка.

Поля automation_fit, design_score, animation_potential, limitations показаны в двух клиентах. data/manifest.json содержит дату, URL и SHA256 текстов/снимков. Материалы не доказывают маркетинговые заявления. Права на страницы принадлежат их владельцам.

## Desktop и сборка

Установи desktop/requirements.txt. Запуск: python desktop/main.py. Сборка: python desktop/build.py. Файл desktop/dist/CompetitorMonitor.exe — клиент: отдельно запущенный backend на порту 8008 обязателен. Ключ в EXE не входит. Режим --self-test C:\temp\pem08-test выполняет один реальный текстовый запрос и сохраняет JSON и снимок окна.

## Проверки

Установи pytest и зависимости из desktop/requirements.txt; выполни python -m pytest -q и node tests/test_frontend.cjs. Проверяются схема, диапазоны, файлы, URL, история и конкурентная запись, недоступный backend, MIME desktop-клиента и экранирование HTML. Тесты PyQt6 работают без видимого окна и реальных API-вызовов: они проверяют отзывчивость окна, обработку ошибок истории, буквальное отображение HTML и адреса разрешённых сервисов.

Успешно выполнены шесть реальных анализов: текст и снимок каждого сервиса. Selenium → снимок → модель → история проверен на n8n. Живой Selenium для остальных двух сайтов не заявляется.

## Ограничения

Правильный JSON не гарантирует достоверность. В реальных ответах встречались английский язык вопреки инструкции, неподтверждённые слабые стороны и неверное толкование потенциала анимации как функции сервиса. limitations тоже формирует модель и оно может ошибаться. Выводы требуют ручной сверки; оценки дизайна субъективны. По одному снимку нельзя подтвердить анимацию, цены или надёжность. PDF не поддерживается.

В изолированной среде Windows Chrome падал с tab crashed; в обычной среде с защитой браузера парсинг прошёл. Не отключайте sandbox или TLS для обхода ошибок. При некорректной структуре ответа показана ошибка, без записи успешного результата.
